## Как открыть сайт

1. Откройте любой современный браузер: Chrome, Safari, Firefox, Yandex или Edge.
2. В адресной строке введите домен сайта (будет утверждён на этапе деплоя, например `businka-rnd.ru`).
3. Нажмите Enter.

Сайт загрузится автоматически. Никакая регистрация или авторизация не требуется.

## Главная страница

Главная — это длинный лендинг, который знакомит с брендом. Сверху вниз вы увидите:

1. **Шапка (header)** — логотип «БУСИНКА украшения из бисера» слева и пункты меню справа.
2. **Hero-блок** — крупная фраза «Украшения, созданные для тебя» и кнопка перехода в каталог.
3. **Блок «Каталог»** — превью категорий: серьги, кольца, браслеты, брелоки.
4. **Блок «Удивляй»** — эмоциональное приглашение делать подарки близким.
5. **Блок «Популярное»** — лучшие украшения месяца.
6. **«Почему мы?»** — три причины выбрать Бусинку.
7. **Мастер-класс** — приглашение на занятие.
8. **Футер (footer)** — контакты, адрес, соцсети.

Прокручивайте страницу колесом мыши, тачпадом или свайпом на телефоне.

## Меню навигации

В верхней части сайта (header) находится главное меню с четырьмя пунктами:

| Пункт | Куда ведёт |
|---|---|
| Новости | Страница `/news` с анонсами и событиями |
| Каталог | Страница `/catalog` со всеми украшениями |
| О нас | Страница `/about` с историей бренда |
| Отзывы | Страница `/reviews` с впечатлениями клиентов |

Кликните по логотипу слева — вы вернётесь на главную страницу с любого раздела.

### Меню на телефоне

На экранах меньше 800 пикселей меню сворачивается в «бургер» — иконку из трёх горизонтальных полосок справа от логотипа.

1. Нажмите на иконку «бургер».
2. Откроется выпадающее меню с теми же пунктами.
3. Выберите нужный раздел.
4. Чтобы закрыть меню без перехода, нажмите крестик в правом верхнем углу.

## Запись на мастер-класс

На главной странице есть отдельный блок «Мастер-класс». Чтобы записаться:

1. Прокрутите главную до блока «Мастер-класс».
2. Нажмите кнопку «Записаться».
3. Откроется Telegram с готовым сообщением о записи.
4. Отправьте сообщение мастеру — он подтвердит дату и время.

Стоимость, продолжительность и список тем мастер-классов уточняйте в личном чате — расписание гибкое.

![Скриншот: блок мастер-класса](screenshots/master-class.png)

## Страница «не найдено»

Если вы ввели неправильный адрес (например, `/shop` — такого раздела нет), откроется фирменная страница 404.

На ней:

- Иллюстрация в стиле бренда.
- Сообщение, что страница не найдена.
- Кнопка «Вернуться на главную» — она вернёт вас на `/`.

## Просмотр с телефона

Сайт полностью адаптирован под мобильные устройства. Особенности мобильной версии:

| Элемент | Поведение |
|---|---|
| Меню | Скрывается в «бургер» |
| Карточки каталога | Выстраиваются в одну колонку |
| Hero-блок | Текст и кнопка располагаются вертикально |
| Футер | Колонки контактов объединяются в одну |
| Шрифты | Автоматически уменьшаются |

### Рекомендации

- Используйте свежие версии браузеров (Safari 15+, Chrome 100+).
- Для лучшего опыта включите автоповорот экрана — некоторые карточки красивее смотрятся в ландшафтной ориентации.
- При плохом интернете изображения могут подгружаться с задержкой — это нормально.
