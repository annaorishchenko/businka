## Обнаруженные дефекты

### DEF-001 — Ховер-зона бургер-кнопки и кнопки закрытия частично перекрывается

**Тяжесть**: minor (косметика, не функциональный сбой).
**Шаги**: При очень узком вьюпорте (320px) close-button (внутри открытого мобайл-меню) может визуально пересекаться с верхней частью логотипа.
**Текущее поведение**: всё кликается, функциональность сохранена.
**Ожидаемое**: отступы между логотипом и кнопкой ≥ 8px.
**Рекомендация**: добавить `min-width: 56px` для контейнера логотипа в мобайл-меню или увеличить gap.

## Рекомендации

1. **Оптимизация изображений (high priority)**: PNG-файлы товаров занимают по 1-2 МБ. Конвертировать в WebP/AVIF, уменьшить разрешение до 800×800. Это сократит размер сборки с 22 МБ до ~3 МБ.
2. **Lazy loading изображений**: уже включён `loading="lazy"` на `<Card>` и `<Article>`, но имеет смысл добавить `decoding="async"` и явные `width/height` для CLS.
3. **Прогрев Suspense-чанков**: при первом переходе на /catalog видна короткая «загрузка». Префетч через `<link rel="prefetch">` на популярные маршруты.
4. **Sitemap.xml + robots.txt**: добавить для SEO перед публикацией.
5. **Тест на реальном Safari/Firefox**: проверки делались в Chromium preview-engine. Перед запуском в продакшен прогнать кросс-браузерно на 6 браузерах из ТЗ.

## Регрессионный сценарий (smoke)

5-минутный обход для предрелизных проверок:

1. Открыть `/` — Hero отображается, фото грузится.
2. Перейти на `/catalog` — видны фильтры, сетка карточек.
3. Кликнуть один из фильтров — список сократился, чип активен.
4. Открыть `/news`, `/about`, `/reviews` — каждая страница рендерится без ошибок в консоли.
5. Открыть `/no-such-page` — отображается 404, кнопка «На главную» работает.
6. Прокрутить футер — телефон/email/Telegram кликабельны, дисклеймер про Meta виден.
7. Уменьшить окно до 375px — навигация превращается в бургер, секции в одну колонку.
8. Открыть бургер-меню — все 4 пункта присутствуют, навигация работает, меню закрывается после клика по ссылке.
