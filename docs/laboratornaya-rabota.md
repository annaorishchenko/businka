## 1. Формирование требований к сайту

Заказчик хочет:

Тип сайта: сайт-визитка (бренд украшений ручной работы из бисера «Бусинка»).

У сайта должно быть две формы: десктопная и мобильная.

У сайта должно быть несколько страниц:

- Главная
- Новости
- Каталог
- О нас
- Отзывы
- Обратная связь (контакты в подвале)

## 2. Разработка концепции сайта

Тип сайта: сайт-визитка (бренд украшений «Бусинка», г. Ростов-на-Дону).

У сайта должно быть две формы с разным разрешением для каждой: десктопная (1920×1080) и мобильная (800×600 и менее).

Сайт должен одинаково корректно отображаться в следующих веб-браузерах: Atom, Edge, Firefox, Google Chrome, Opera, Safari, Mobile Safari, Яндекс.Браузер.

У сайта должно быть несколько страниц:

- Главная (длинный лендинг бренда)
- Каталог (сетка карточек украшений с фильтром по категориям)
- Новости (периодические новости о новых коллекциях, мастер-классах, выездах)
- О нас (история бренда, преимущества)
- Отзывы (отзывы клиентов с оценкой)
- 404 (страница не найдена)

Воронка продаж (целевые показатели на запуск):

- 3000 (ежедневное посещение); 1000 → 1 (воронка); 2 500 (средний удельный чек).
- Ежедневно бренд приобретает товар: ориентировочно 3 человека.

## 3. Техническое задание

### Общие требования

Сайт должен быть разработан без использования системы управления сайтами. Сайт должен быть разработан на React (Vite + React 18 + TypeScript). После окончания работ необходимо, чтобы Исполнитель по команде Заказчика самостоятельно вносил изменения в содержимое сайта (новость, изменение перечня продуктов или услуг, добавление новых отзывов и т.д.).

По окончании работ Исполнитель обязан предоставить полностью функционирующий сайт, все исходные коды и графические материалы по дизайну, все необходимые данные для доступа к управлению сайтом (аккаунты, пароли, адреса серверов и т.п.). Исполнитель обязуется не использовать интеллектуальную собственность, полученную в ходе разработки и создания сайта, в иных коммерческих проектах, если это будет наносить ущерб Заказчику. Заказчик может предоставить право использования материала со своего письменного согласия.

### Требования к дизайну сайта

Дизайн сайта не должен быть пёстрым. Использовать преимущественно оттенки кремового, светло-розового и бронзового цветов (палитра из Figma: `#FEFBEA`, `#FDE6DB`, `#D58D98`, `#DC919C`, `#9B8E5A`). Текст сайта должен быть написан шрифтом тёмно-коричневого цвета `#3B342A` (ссылки оформляются по умолчанию или с акцентом на цвет `#D58D98`). Дизайн сайта должен быть выполнен с использованием языка HTML и CSS (графические объекты должны быть выполнены с использованием SVG-графики и/или вставки картинок типа png/jpg/webp).

Сайт должен корректно отображаться в следующих браузерах:

- Atom;
- Edge;
- Firefox;
- Google Chrome;
- Opera;
- Safari;
- Mobile Safari;
- Яндекс.Браузер.

Сайт должен корректно отображаться в следующих разрешениях:

- 1920×1080;
- 1366×768;
- 800×600;
- 480×800 и менее (мобильные).

Необходимо создать структуру (шаблон) сайта, состоящую из следующих элементов:

1. **«Header» (хедер).** Содержит логотип «БУСИНКА украшения из бисера» слева и горизонтальное меню навигации справа (Новости, Каталог, О нас, Отзывы). Блок находится сверху страницы и не является закреплённым над остальными элементами. Цвет фона — кремовый `#FEFBEA`, занимает не более 10% экранной высоты.

2. **«Main» (мэйн).** Блок находится между элементами Header и Footer, занимает всё доступное пространство и не является закреплённым над остальными элементами. Содержит секции страницы, выводимые роутингом. По бокам — декоративные элементы-висюльки (SVG, скрываются на разрешениях менее 1024 px). Цвет фона — кремовый `#FEFBEA` с акцентами `#FDE6DB`.

3. **«Footer» (футер).** Содержит контактную информацию о бренде («Бусинка»): адрес (г. Ростов-на-Дону, ул. Максима Горького, 75), режим работы (9:00 — 20:00), телефон (+7 906 415 17 82), e-mail (businka@mail.ru), ссылки на Telegram и Instagram, ссылки на политику обработки персональных данных и политику конфиденциальности, дисклеймер о признании Meta экстремистской организацией. Блок находится внизу страницы и не является закреплённым над остальными элементами. Цвет фона — градиент от `#FEFBEA` к `#FDE6DB`. Если страница маленькая, то футер прикреплён к низу экрана (через `min-height: 100vh` родителя и `margin-top: auto`). Блок занимает не более 30% экранной высоты в обычных условиях.

### Детальное описание страниц сайта

**Страница «Главная»**

Страница вертикально поделена на блоки: Header, длинный лендинг (Hero + блок Каталог + блок Удивляй + Популярное + Почему мы + Мастер-класс), Footer. Контент:

- В Hero — название бренда «Бусинка», заголовок «Украшения, созданные для тебя», лид-текст про ручную работу и кнопки CTA «Перейти в каталог» / «Связаться».
- В каждой секции — заголовок-eyebrow (например, «КАТАЛОГ») и script-заголовок (например, «Удивляй»).

**Страница «Каталог»**

Страница вертикально поделена на блоки: Header, основной блок, Footer. Основной блок содержит заголовок «Украшения, созданные вручную», ряд фильтр-чипов (Всё / Серьги / Кольца / Браслеты / Колье / Брелоки / Фигурки) и сетку карточек товаров (4 колонки на 1920, 3 на 1366, 2 на 800, 1 на 480).

**Страница «Новости»**

Страница вертикально поделена на блоки: Header, основной блок, Footer. Основной блок содержит заголовок «О чём мы пишем» и список карточек с датой, заголовком и описанием новости.

Тегом `h1` написано «О чём мы пишем».
Тегом `h2` (в каждой карточке) — заголовок новости.
Тегом `time` — дата публикации.

**Страница «О нас»**

Страница вертикально поделена на блоки: Header, основной блок, Footer. Основной блок содержит заголовок «Маленький бренд с большой душой», текст-сторителлинг о бренде «Бусинка» и блок «Почему мы?» с тремя преимуществами (Универсальный стиль / Ручная работа / Качественные материалы).

Тегом `h1` написано «Маленький бренд с большой душой».

**Страница «Отзывы»**

Страница вертикально поделена на блоки: Header, основной блок, Footer. Основной блок содержит заголовок «Что говорят клиенты» и сетку карточек с именем клиента, городом, оценкой (1–5 звёзд) и текстом отзыва.

Тегом `h1` написано «Что говорят клиенты».

**Страница «404»**

Страница вертикально поделена на блоки: Header, основной блок (60% высоты экрана, по центру), Footer. Тегом `h1` написано «404», тегом `h2` — «Бусинка потерялась», тегом `p` — «Такой страницы нет — возможно, ссылка устарела или вы ввели адрес с опечаткой. Давайте вернёмся к украшениям.». **Дизайнер-интерфейса (UI) и дизайнер-эргономист (UX).**

#### Общая информация

Программный продукт (сайт-визитка «Бусинка») используется для обозначения присутствия в информационно-телекоммуникационной глобальной сети Интернет бренда украшений ручной работы «Бусинка» (г. #### Инструкция по эксплуатации

**I. Загрузка сайта.**

1. В адресной строке необходимо записать следующий адрес: `localhost:3000` (для локального запуска) или `https://businka-rnd.ru` (для production).
2. Необходимо перейти по указанному в предыдущем пункте адресу путём нажатия клавиши `Enter`.

Конечный результат:

Загружена главная страница сайта «Бусинка» с Hero «Украшения, созданные для тебя».

**II. Переход на страницу «Новости».**

1. В хедере находим ссылку «Новости».
2. В хедере нажимаем на ссылку «Новости».

Конечный результат:

Загружена страница `/news` с заголовком «О чём мы пишем» и списком новостей.

**III. Переход на страницу «Каталог».**

1. В хедере находим ссылку «Каталог».
2. В хедере нажимаем на ссылку «Каталог».

Конечный результат:

Загружена страница `/catalog` с заголовком «Украшения, созданные вручную», фильтр-чипами по категориям и сеткой карточек.

**IV. Фильтрация каталога по категории.**

1. На странице `/catalog` находим ряд чипов: «Всё», «Серьги», «Кольца», «Браслеты», «Колье», «Брелоки», «Фигурки».
2. Нажимаем на чип нужной категории (например, «Серьги»).

Конечный результат:

В сетке остаются только товары выбранной категории. Активный чип подсвечивается основным цветом бренда.

Для возврата к полному списку нажмите на чип «Всё».

**V. Переход на страницу «О нас».**

1. В хедере находим ссылку «О нас».
2. В хедере нажимаем на ссылку «О нас».

Конечный результат:

Загружена страница `/about` с заголовком «Маленький бренд с большой душой», историей бренда и блоком преимуществ «Почему мы?».

### Руководство администратора

#### Как приобрести домен

1. Зайти на сайт регистратора (рекомендуется reg.ru / nic.ru / r01) и пройти авторизацию.
2. В поиске свободных доменов ввести желаемое имя (например, `businka-rnd.ru`).
3. При наличии — добавить в корзину и оплатить.
4. Подтвердить владение через e-mail и/или паспортные данные (для зоны `.ru` обязательно).
5. После регистрации — войти в панель управления и убедиться, что домен присутствует в списке.

#### Как организовать сервер с белым IP или приобрести хостинг (чужой сервер)

1. Выбрать VPS-провайдера (рекомендуется Selectel / Timeweb / Hetzner / Beget) и арендовать минимальный тариф (1 vCPU, 1 ГБ RAM, 10 ГБ SSD, Ubuntu 22.04).
2. После активации сервера получить публичный (белый) IP-адрес из панели управления провайдера.
3. Подключиться к серверу по SSH под пользователем `root` через ключ:
   ```bash
   ssh-keygen -t ed25519 -C "businka@deploy"
   ssh-copy-id root@<IP_СЕРВЕРА>
   ssh root@<IP_СЕРВЕРА>
   ```
4. Создать рабочего пользователя с правами `sudo`:
   ```bash
   adduser deploy
   usermod -aG sudo deploy
   ```
5. Отключить вход по паролю и логин под `root` в `/etc/ssh/sshd_config` (`PasswordAuthentication no`, `PermitRootLogin no`), перезапустить SSH: `systemctl restart ssh`.
6. Настроить файрвол:
   ```bash
   ufw allow 22 && ufw allow 80 && ufw allow 443 && ufw enable
   ```
7. Установить `fail2ban` и Docker (по официальной инструкции Docker для Ubuntu).

#### Как привязать домен к серверу

1. В панели регистратора домена открыть раздел «DNS» / «Управление зонами».
2. Создать A-запись:
   - **Host**: `@` (или пусто) → значение: IP сервера.
   - **Host**: `www` → значение: IP сервера.
   - **TTL**: 600 секунд.
3. Дождаться распространения DNS (5–60 минут). Проверить:
   ```bash
   dig +short businka-rnd.ru
   ```

#### Как залить сайт на сервер

1. Подключиться к серверу по SSH под пользователем `deploy`.
2. Клонировать репозиторий:
   ```bash
   git clone https://github.com/<org>/businka.git /opt/businka
   cd /opt/businka
   ```
3. Скопировать и заполнить файл переменных окружения:
   ```bash
   cp .env.example .env
   nano .env   # указать DOMAIN и EMAIL
   ```
4. Собрать и запустить контейнеры:
   ```bash
   docker compose up -d --build web
   ```
5. Открыть в браузере `http://<DOMAIN>` — должна загрузиться главная страница сайта (по HTTP, без SSL).

#### Как выпустить SSL-сертификат

1. В каталоге проекта выполнить:
   ```bash
   chmod +x scripts/init-ssl.sh
   bash scripts/init-ssl.sh
   ```
2. Скрипт автоматически: запросит сертификат через `certbot --webroot`, подставит домен в `nginx-ssl.conf`, заменит активный `nginx.conf` (с бэкапом), перезапустит контейнер `web`.
3. Открыть в браузере `https://<DOMAIN>` — должна загрузиться страница с валидным сертификатом.

#### Как обновить сайт

1. Подключиться к серверу по SSH под пользователем `deploy`.
2. Перейти в директорию проекта и выполнить:
   ```bash
   cd /opt/businka
   bash scripts/deploy.sh
   ```
3. Скрипт выполнит `git pull` → пересборку Docker-образа → перезапуск контейнера → вывод статуса.

#### Как разместить единицу информации (новость / новый отзыв / новый товар)

1. Внести изменение в исходный файл констант:
   - Новости: `src/shared/constants/news.ts` — добавить элемент в массив `NEWS`.
   - Отзывы: `src/shared/constants/reviews.ts` — добавить элемент в массив `REVIEWS`.
   - Товары: `src/shared/constants/products.ts` — добавить элемент в массив `PRODUCTS`.
2. Зафиксировать изменения в git: `git add` + `git commit -m "..."` + `git push`.
3. На сервере выполнить `bash scripts/deploy.sh` (см. выше).
