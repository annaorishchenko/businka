## Резюме проекта

**Бусинка** — сайт-визитка ростовского бренда украшений ручной работы из бисера. Цель сайта — рассказать о бренде, показать каталог изделий, познакомить с историей и пригласить на мастер-классы. Сайт не содержит интернет-магазина и не принимает заявки через формы: все коммуникации происходят по прямым каналам связи (Telegram, телефон, email, Instagram).

| Параметр | Значение |
|---|---|
| Тип проекта | Сайт-визитка (long-form landing + дочерние страницы) |
| Город | Ростов-на-Дону |
| Адрес шоурума | ул. М. Горького, 75 |
| Режим работы | Ежедневно, 9:00–20:00 |
| Способ контакта | Прямые ссылки на мессенджеры/телефон |
| Backend | Отсутствует (статика на nginx) |

## Цели и задачи сайта

### Главная цель

Превратить случайного посетителя в подписчика бренда или заказчика украшения, минуя промежуточные звенья (форму заявки, корзину, оплату).

### Задачи

1. Сформировать первое впечатление о бренде через эстетику главной страницы.
2. Продемонстрировать ассортимент украшений: серьги, кольца, браслеты, брелоки.
3. Рассказать историю мастера и обосновать ценность ручной работы.
4. Опубликовать социальные доказательства — отзывы покупателей.
5. Информировать о мастер-классах и приглашать к участию.
6. Обеспечить быстрый одноклик-переход в Telegram и звонок по телефону.

### Не-цели (out of scope)

- Онлайн-оплата и корзина.
- Личный кабинет покупателя.
- Формы обратной связи с отправкой данных на сервер.
- Многоязычность (только русский).
- Блог с CMS-редактором.

## Структура сайта

Сайт состоит из шести маршрутов. Меню навигации в header содержит четыре пункта: **Новости**, **Каталог**, **О нас**, **Отзывы**. Слева — логотип «БУСИНКА украшения из бисера», ведущий на главную. Контакты вынесены в футер.

### Главная — `/`

Длинный одностраничный лендинг, состоящий из секций:

1. **Hero** — крупный заголовок «Украшения, созданные для тебя», фоновое изображение и CTA-кнопка перехода в каталог.
2. **Блок «Каталог»** — превью категорий: серьги, кольца, браслеты, брелоки, с кнопкой «Посмотреть всё».
3. **Блок «Удивляй»** — эмоциональный блок про подарки и индивидуальность.
4. **Популярное** — карусель/сетка из 4–6 хитов продаж.
5. **Почему мы?** — три преимущества: качественные материалы, ручная работа, универсальный стиль.
6. **Мастер-класс** — приглашение записаться на занятие, кнопка-переход в Telegram.

### Каталог — `/catalog`

Сетка карточек украшений, сгруппированных по категориям (серьги, кольца, браслеты, брелоки). Каждая карточка содержит изображение, название, краткое описание и тег категории. При клике на карточку — переход в Telegram-чат с заранее подготовленным сообщением.

### Новости — `/news`

Сетка карточек с анонсами событий бренда: новые коллекции, скидки, участие в ярмарках. Дизайн карточек оригинальный, в палитре бренда. Контент статичный (правится разработчиком в коде).

### О нас — `/about`

Объединяет блок «Почему мы?», историю основательницы и три ключевых преимущества:

- **Качественные материалы** — бисер премиум-класса, фурнитура с гипоаллергенным покрытием.
- **Ручная работа** — каждое изделие создаётся индивидуально.
- **Универсальный стиль** — украшения подходят под повседневный и вечерний образ.

### Отзывы — `/reviews`

Сетка карточек с отзывами клиентов. Каждая карточка: имя, текст отзыва, рейтинг (звёзды 1–5). Дизайн оригинальный, в палитре бренда.

### 404 — `*`

Страница «не найдено» с фирменной иллюстрацией, сообщением и кнопкой «Вернуться на главную».

## Карта пользовательских сценариев

### Сценарий 1. Поиск подарка

1. Пользователь приходит из поисковика по запросу «украшения из бисера Ростов».
2. Попадает на главную, видит Hero и листает лендинг.
3. Переходит в раздел «Каталог», выбирает категорию «Серьги».
4. Кликает на понравившуюся карточку — открывается Telegram с готовым сообщением.
5. Договаривается о заказе.

### Сценарий 2. Запись на мастер-класс

1. Пользователь приходит по ссылке из Instagram-сторис.
2. Видит на главной блок «Мастер-класс».
3. Кликает «Записаться» — открывается Telegram.
4. Получает расписание и записывается.

### Сценарий 3. Изучение бренда

1. Пользователь приходит по рекомендации подруги.
2. Открывает «О нас», читает историю.
3. Переходит в «Отзывы», убеждается в качестве.
4. Заходит в «Каталог», сохраняет страницу в закладках.

### Сценарий 4. Проверка адреса шоурума

1. Пользователь уже клиент, хочет приехать в шоурум.
2. Скроллит сразу в футер.
3. Видит адрес, время работы, номер телефона.
4. Кликает «Позвонить», уточняет наличие.

### Сценарий 5. Получение новостей

1. Пользователь хочет узнать о новых коллекциях.
2. Открывает «Новости».
3. Читает анонс ярмарки, делает скриншот, идёт на мероприятие.
